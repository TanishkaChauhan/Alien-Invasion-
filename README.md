Alien Invasion
This is a classic arcade-style shooter game where you control a rocket ship and defend Earth from an invading fleet of aliens. The game was built using Python and the Pygame library.

Game Description
In Alien Invasion, you pilot a rocket ship positioned at the bottom center of the screen. Your mission is to destroy the alien fleet that descends from the sky. The game features a dynamic difficulty system, increasing the challenge as you successfully eliminate alien ships.

Features
Player Ship Controls: Move your ship left and right using the arrow keys.

Shooting Mechanics: Fire bullets by pressing the spacebar.

Dynamic Difficulty: The alien fleet becomes faster with each wave you defeat.

Lives System: You have a limited number of lives, which decrease if an alien hits your ship or reaches the bottom of the screen.

Game Over Screen: The game concludes when you run out of lives.

Technical Requirements
To run this game, you will need:

Python 3.x

The Pygame library

You can install Pygame using the following command in your terminal:

pip install pygame

How to Play
Move: Use the left and right arrow keys to move your rocket ship.

Shoot: Press the spacebar to fire bullets.
